# 📚 Каталог словарей для Yomitan

Сборник готовых `.zip` словарей для браузерного расширения [Yomitan](https://github.com/themoeway/yomitan) (бывший Yomichan). Архивы уже сконвертированы в формат Yomitan (внутри находятся `index.json` и банки терминов) и готовы к импорту без дополнительной настройки.

> 👤 **Автор сборки и конвертации баз:** [@budaevw](https://github.com/budaevw)  
> 📦 **Хранилище всех файлов:** [t.me/yomitan_dict](https://t.me/yomitan_dict)  
> *Этот репозиторий служит навигатором-каталогом с описанием словарей, уровней и ссылками на скачивание.*

---

### Направления перевода в коллекции:
* 🎯 **Толковые (моноязычные):** *EN-EN, DE-DE, RU-RU, KK-KK*. Помогают понимать смысл напрямую, без мысленного перевода на русский.
* 🇷🇺 **С иностранного на русский:** *EN-RU, FR-RU, ES-RU, ZH-RU и др.* Основные базы для чтения книг, статей и просмотра видео с субтитрами.
* 🔄 **С русского на иностранный:** *RU-EN, RU-IT, RU-ES, RU-KK и др.* Пригодятся при чтении русскоязычных материалов или для изучающих русский язык.
* 🌍 **Между иностранными языками:** *EN-UK, KK-EN, HY-EN, HE-EN*. Двуязычные базы без русского языка.

## ⚙️ Инструкция по установке

1. Скачайте нужный архив `.zip` из [Telegram-хранилища](https://t.me/yomitan_dict). **Архив распаковывать не нужно!**
2. В браузере откройте настройки **Yomitan** (значок расширения ➔ шестерёнка).
3. В левой панели выберите вкладку **Dictionaries** (Словари).
4. Нажмите кнопку **Import dictionary** (Импортировать словарь).
5. Выберите скачанный `.zip` файл и дождитесь окончания загрузки.
6. Включите тумблер рядом с добавленным словарем в списке.

## ❓ Частые вопросы (FAQ)

**Yomitan выдает ошибку при импорте:**
* Убедитесь, что внутри архива файлы (`index.json` и банки терминов) лежат прямо в корне, а не во вложенной папке.
* Не распаковывайте ZIP перед импортом.
* Проверьте размер файла: при нестабильном интернете архив мог скачаться не полностью.

**Работает ли это на смартфоне?**
* Да. На Android можно поставить браузер с поддержкой расширений Chrome (например, **Kiwi Browser** или **Firefox Nightly**), установить расширение Yomitan и импортировать те же самые `.zip` архивы.

**В чем разница между обычной версией и Compact?**
* В версиях Compact убраны примеры употребления и объемные цитаты. Остается только прямой перевод, благодаря чему окно выдачи занимает меньше места при чтении.
